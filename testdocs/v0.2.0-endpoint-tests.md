# Endpoint Tests — v0.2.0

**Auth server version**: v0.2.0 (Stabilization)  
**Date tested**: 2026-05-30  
**Base URL**: `http://localhost:8080`  
**Server start**: `go run ./cmd/iam-server/...` from `auth-server/`

---

## Setup

### Start the server
```bash
cd auth-server
go run ./cmd/iam-server/...
```

### Environment variables (set before starting)
```
DATABASE_URL=postgres://...
REDIS_URL=redis://...
NATS_URL=nats://...
```

### Reset state between full test runs
```bash
docker exec -it <postgres-container> psql -U postgres -d authdb \
  -c "TRUNCATE identities, users, tenants, sessions, credentials, roles, permissions, user_roles, role_permissions CASCADE;"
```

## Known Issues (v0.2.0)

| # | Endpoint | Issue | Expected | Actual |
|---|----------|-------|----------|--------|
| 1 | `POST /users` | Missing `role_name` returns 500 | 400 Bad Request | 500 Internal Server Error |
| 2 | `POST /roles/{id}/permissions` | Non-existent permission name returns 500 | 400/404 | 500 Internal Server Error |
| 3 | All endpoints | Refresh token sent in JSON body (XSS risk) | HTTP-only cookie | JSON body |
| 4 | All endpoints | `X-Session-ID` header (non-standard) | `Authorization: Bearer` | `X-Session-ID` |
| 5 | Session table | Expired/revoked sessions accumulate indefinitely | Background cleanup | No cleanup |
