# v0.7.0 — WebAuthn / Passkeys

Adds passkey registration and passwordless passkey login using discoverable credentials (resident keys). Built on `github.com/go-webauthn/webauthn`.

## New components

- `migrations/000005_webauthn_credentials.up.sql` — `webauthn_credentials` (id, identity_id, credential_id, public_key, attestation, aaguid, sign_count, transports, user_handle, label, timestamps)
- `internal/webauthn/domain/credential.go` — `Credential`, `Repository`
- `internal/webauthn/infra/postgres/repository.go` — postgres implementation
- `internal/webauthn/app/user.go` — `WAUser` implements the library's `User` interface
- `internal/webauthn/app/session_store.go` — Redis-backed ceremony session, 5-min TTL
- `internal/webauthn/app/service.go` — wraps `wa.WebAuthn`; `BeginRegistration`, `FinishRegistration`, `BeginLogin` (discoverable), `FinishLogin`
- `internal/webauthn/app/login_complete.go` — passkey login → session + JWT (same shape as password login)
- `internal/webauthn/transport/http/handler.go` — HTTP endpoints
- `internal/platform/config/config.go` — added `WebAuthnRPID`, `WebAuthnName`, `WebAuthnOrigin` (env: `WEBAUTHN_RPID`, `WEBAUTHN_NAME`, `WEBAUTHN_ORIGIN`)

## New routes

| Route | Auth | Notes |
|---|---|---|
| `POST /webauthn/register/begin` | yes | returns `{session_key, options}`; options are `PublicKeyCredentialCreationOptions` |
| `POST /webauthn/register/complete` | yes | `{session_key, label, response}` |
| `GET /webauthn/credentials` | yes | list user's passkeys |
| `POST /webauthn/login/begin` | no | discoverable credential challenge |
| `POST /webauthn/login/complete` | no | `{session_key, response}` → session + JWT (same shape as password login) |

## Design

- **Passkeys / discoverable credentials**: registration requires `ResidentKeyRequired`; login uses `BeginDiscoverableLogin` (no username required from the user).
- **User handle**: random `[]byte`, stable across an identity's credentials. First credential creation seeds it from `identity_id`; subsequent credentials reuse the same handle.
- **Sign-count**: stored per credential; updated on every successful login to detect cloned authenticators.

## Dependencies added

- `github.com/go-webauthn/webauthn` (with transitive `cbor`, `mapstructure`, `go-tpm`, etc.)

## Operational steps

1. `docker exec -i auth-server-postgres psql -U authadmin -d authserver < migrations/000005_webauthn_credentials.up.sql`
2. Set `WEBAUTHN_RPID` (e.g. `localhost` for dev, your domain in prod) and `WEBAUTHN_ORIGIN` (the URL the browser sees, e.g. `https://app.example.com`).
3. Restart `iam-server`.

## Notes

- WebAuthn requires a real browser/authenticator (Touch ID, Windows Hello, YubiKey, passkey from iCloud/Google Password Manager). The server endpoints return spec-compliant options; full E2E verification is exercised from a browser client.
- `RPID` must be a registrable domain matching the origin's host; `RPOrigins` must include the exact origin (scheme + host + optional port).
