# v0.3.0 — JWT Access Tokens

Login and refresh now issue short-lived ES256 JWTs alongside the existing opaque refresh tokens. Authentication middleware accepts `Authorization: Bearer <JWT>` and validates statelessly (no DB lookup). The refresh token is also delivered as an HTTP-only `SameSite=Strict` cookie for browser clients while remaining in the JSON body for mobile/CLI clients.

## New / changed components

- `migrations/000004_signing_keys.up.sql` — `signing_keys` (id, algorithm, public_key, private_key, is_active, created_at, rotated_at)
- `internal/token/domain/` — `SigningKey`, `Claims`, `Repository`
- `internal/token/infra/postgres/repository.go` — postgres implementation
- `internal/token/app/jwt_service.go` — Issue + Verify (ES256/RS256 support)
- `internal/token/app/keygen.go` — ES256 / RS256 key pair generation
- `internal/token/transport/http/jwks.go` — `GET /.well-known/jwks.json` with `Cache-Control: max-age=3600`
- `cmd/key-rotator/main.go` — implemented; `-alg ES256|RS256` flag, deactivates previous keys, inserts new active key
- `internal/auth/app/login.go` — loads permissions, issues JWT; new fields `AccessToken`, `ExpiresIn`, `Permissions`
- `internal/auth/app/refresh.go` — also loads identity + roles + permissions and issues new JWT on rotation
- `internal/auth/middleware/authentication.go` — checks `Authorization: Bearer` first, falls back to `X-Session-ID`
- `internal/auth/transport/http/response.go` — `setRefreshCookie`, `clearRefreshCookie` helpers
- `internal/auth/transport/http/refresh.go` — reads refresh token from cookie OR JSON body
- `internal/auth/transport/http/logout.go` — clears refresh cookie
- `internal/platform/config/config.go` — added `JWTIssuer` (`JWT_ISSUER` env, default `http://localhost:8080`)

## New route

- `GET /.well-known/jwks.json` — public JWK set, cacheable

## Token delivery

| Token | Where |
|---|---|
| `access_token` (JWT, 15 min) | JSON body |
| `refresh_token` (opaque, 7 days) | JSON body **and** `Set-Cookie: refresh_token=...; HttpOnly; Secure; SameSite=Strict` |

## Dependencies added

- `github.com/golang-jwt/jwt/v5`

## Operational steps

1. `docker exec -i auth-server-postgres psql -U authadmin -d authserver < migrations/000004_signing_keys.up.sql`
2. `go run ./cmd/key-rotator/... -alg ES256` (or `RS256`)
3. Restart `iam-server`
